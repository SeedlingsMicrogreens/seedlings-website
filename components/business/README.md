# Shared Business UI Foundation

Phase 3 establishes reusable presentation boundaries for common customer
business UI:

- Product Card
- Cart Item
- Address Card
- Subscription Card
- Order Card
- Price Display
- Quantity Control

## Important

These are component boundaries, not replacements for existing application
implementations.

No existing page is migrated in Phase 3.

Existing pricing, inventory, payment, subscription, order, address, and
authentication logic remains the source of truth.

Actual component extraction/migration starts page-by-page after this foundation
is approved.
