# Shared Layout Foundation

Phase 2 introduces standardized React boundaries for:

- Header
- Footer
- Mobile navigation
- Page shell
- Page section
- Container

## Important

These components are intentionally structural and presentation-neutral.

The existing website Header/Footer/navigation implementations are NOT replaced
in this phase. Page migration is performed later, one page/flow at a time,
after matching existing UX/UI and functionality.

Standardization means changing implementation structure, not changing the
customer experience.
